# Topper v14.5.5 UI refinement

- Dark neutral translucent overlay treatment based on the supplied visual reference.
- Existing font sizes are unchanged; font family uses Arial with Segoe UI fallback.
- Existing overlay/window launch dimensions are unchanged.
- Go Back and Start Listening are grouped at the top-center of the pre-listening panel and constrained inside the overlay.
- No backend, OpenAI, streaming, STT, RAG, prompt, IPC, licensing, commerce, or latency-path code was changed.
- Existing cursor/capture-protection implementation was left unchanged.
